Mobile Kiosk System

Developed by Jolan Clark A. Sorillo. A specialized Android kiosk shell designed for device rental management, automated countdown timers, PIN-secured admin settings, and app access restriction.

  • First-Time Setup Wizard: Initial configuration flow for business name, admin PIN, and system overlay permissions.
  • PIN-Protected Admin Lock: Restricts settings and prevents unauthorized system exit.
  • Automated Session Countdown: Displays rental timer and notifies users upon expiration.
  • App Allow-List Control: Restricts device usage to permitted applications only.
